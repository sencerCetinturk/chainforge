# API Key Bağla (opsiyonel)

ChainForge, ücretsiz modellerle **hiçbir key olmadan** hemen çalışır — bu adımı atlayabilirsin.

Daha güçlü modellere (Claude, GPT, Gemini vb.) erişmek istersen:

1. [openrouter.ai/keys](https://openrouter.ai/keys) adresinden ücretsiz bir hesap aç.
2. Aldığın key'i ChainForge panelinin **Ayarlar** sekmesine yapıştır.

Key olmadan devam etmek istersen, bir sonraki adıma geç.
