# Agent İle Dosya Düzenlet

Görevini doğal dille yaz, "Dosyalara uygula" kutucuğunu işaretle ve gönder. ChainForge:

1. Görevi planlar, gerekirse araştırma yapar
2. Kodu yazar
3. Değişikliği **diff olarak önizler** — sen onaylamadan hiçbir dosya değişmez
4. Onayladığın değişiklikleri uygular ve loglar

Bir şey ters giderse **"↩ Son Değişikliği Geri Al"** butonuyla tek tıkla eski haline dönebilirsin.
